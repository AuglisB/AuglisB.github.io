# Brandon's Cloud & Infrastructure Portfolio

A lightweight personal portfolio designed for GitHub Pages.

## Before publishing

Open `index.html` and replace:

- `YOUR_GITHUB_USERNAME` with your actual GitHub username
- `YOUR_LINKEDIN` with the final part of your LinkedIn profile URL
- Update any project wording that you want to change

## GitHub Pages setup

1. Create a new public repository named exactly:
   `YOUR_GITHUB_USERNAME.github.io`
2. Upload `index.html` and `styles.css`
3. Open the repository's **Settings**
4. Open **Pages**
5. Set the publishing source to the `main` branch and `/ (root)` if GitHub has not already detected it
6. Visit:
   `https://YOUR_GITHUB_USERNAME.github.io`

## Files

- `index.html` — portfolio content
- `styles.css` — design and responsive layout
